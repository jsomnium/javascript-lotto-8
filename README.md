# 로또 발매기
우아한 테크코스 프리코스 3주차 과제

## 기능 명세
### 요약

1. 로또 구입 금액을 입력받는다.
   - 시스템 입출력 예시
      - 출력: 구입금액을 입력해주세요.
      - 입력: 8000
   - 제한 사항
      - 구입 금액은 1,000원 단위로 입력받는다.
2. 발행한 로또 수량 및 번호를 출력한다.
   - 시스템 입출력 예시
      - 출력: N개를 구매했습니다.
      - [1, 3, 5, 14, 22, 45]
   - 제한 사항
      - 로또 번호는 오름차순으로 정렬하여 보여준다.
3. 당첨 번호를 입력받는다.
   - 시스템 입출력 예시
      - 출력: 당첨 번호를 입력해 주세요.
      - 입력: 1,2,3,4,5,6
   - 제한 사항
      - 로또 번호는 1부터 45 사이의 숫자여야 한다.
      - 번호는 쉼표(,)를 기준으로 구분한다.
      - 로또 번호는 6개여야 한다.
4. 보너스 번호를 입력받는다.
   - 시스템 입출력 예시
      - 출력: 보너스 번호를 입력해주세요.
      - 입력: 7
   - 제한 사항
      - 보너스 번호는 1부터 45 사이의 숫자여야 한다.
5. 당첨 내용을 출력한다.
   - 시스템 입출력 예시
      - 출력: 당첨 통계
      - ---
      - 3개 일치 (5,000원) - 1개 ...
6. 수익률을 출력한다.
   - 시스템 입출력 예시
      - 출력: 총 수익률은 NN:N%입니다.
   - 제한 사항
      - 소수점 둘째 자리에서 반올림한다.

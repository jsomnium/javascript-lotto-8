# 로또 발매기

우아한 테크코스 프리코스 3주차 과제

# 기능 명세

1. 로또 구입 금액을 입력받는다.
   - 시스템 입출력 예시
      - 출력: 구입금액을 입력해주세요.
      - 입력: 8000
   - 제한 사항
      - 구입 금액은 1,000원 단위로 입력받는다.
2. 발행한 로또 수량 및 번호를 출력한다.
   - 시스템 입출력 예시
      - 출력: N개를 구매했습니다.
      - [1, 3, 5, 14, 22, 45]
   - 제한 사항
      - 로또 번호는 오름차순으로 정렬하여 보여준다.
3. 당첨 번호를 입력받는다.
   - 시스템 입출력 예시
      - 출력: 당첨 번호를 입력해 주세요.
      - 입력: 1,2,3,4,5,6
   - 제한 사항
      - 로또 번호는 1부터 45 사이의 숫자여야 한다.
      - 번호는 쉼표(,)를 기준으로 구분한다.
      - 로또 번호는 6개여야 한다.
      - 중복되는 로또 번호는 입력 불가능하다.
4. 보너스 번호를 입력받는다.
   - 시스템 입출력 예시
      - 출력: 보너스 번호를 입력해주세요.
      - 입력: 7
   - 제한 사항
      - 보너스 번호는 1부터 45 사이의 숫자여야 한다.
      - 기존에 입력받은 로또 번호와 중복 불가능하다.
5. 당첨 내용을 출력한다.
   - 시스템 입출력 예시
      - 출력: 당첨 통계
      - ---
      - 3개 일치 (5,000원) - 1개 ...
6. 수익률을 출력한다.
   - 시스템 입출력 예시
      - 출력: 총 수익률은 NN:N%입니다.
   - 제한 사항
      - 소수점 둘째 자리에서 반올림한다.

# Use Case description

### Use Case 1: 로또 구입 금액 입력

| 항목                   | 내용                                                                                                             |
| -------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Actor (사용자)**      | 사용자는 로또를 구매하기 위해 구입 금액을 입력한다.                                                                                  |
| **System (시스템)**     | 시스템은 “구입금액을 입력해주세요.” 문구를 출력하고, 입력값을 검증한다.                                                                      |
| **Precondition**     | 프로그램이 실행 중이며, 로또 구입 단계이다.                                                                                      |
| **Main Flow**        | 1. 시스템이 “구입금액을 입력해주세요.”를 출력한다.<br>2. 사용자가 구입 금액을 입력한다.<br>3. 시스템이 금액이 1,000원 단위인지 확인한다.<br>4. 유효한 경우 입력을 저장한다. |
| **Alternative Flow** | - 금액이 1,000원 단위가 아닐 경우 “[ERROR] 금액은 1,000원 단위로 입력해야 합니다.”를 출력한다.                                                       |
| **Postcondition**    | 유효한 구입 금액이 시스템에 저장된다.                                                                                          |


### Use Case 2: 로또 발행 및 번호 출력

| 항목                | 내용                                                                                                                            |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **Actor (사용자)**   | 사용자는 입력한 금액만큼 로또를 구매한다.                                                                                                       |
| **System (시스템)**  | 시스템은 구입 금액을 1,000으로 나눈 개수만큼 로또를 발행하고, 각 로또 번호를 오름차순으로 출력한다.                                                                   |
| **Precondition**  | 유효한 구입 금액이 입력되어 있다.                                                                                                           |
| **Main Flow**     | 1. 시스템이 발행할 로또 개수를 계산한다.<br>2. 로또 번호 6개를 1~45 사이 난수로 생성한다.<br>3. 각 로또 번호를 오름차순으로 정렬한다.<br>4. 시스템이 “N개를 구매했습니다.”와 함께 번호를 출력한다. |
| **Postcondition** | 발행된 로또 번호 리스트가 저장된다.                                                                                                          |


### Use Case 3: 당첨 번호 입력

| 항목                   | 내용                                                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Actor (사용자)**      | 사용자는 당첨 번호 6개를 쉼표(,)로 구분하여 입력한다.                                                                                     |
| **System (시스템)**     | 시스템은 입력된 번호가 유효한 범위(1~45)인지, 중복이 없는지, 개수가 6개인지 검증한다.                                                                 |
| **Precondition**     | 로또가 발행된 상태이다.                                                                                                        |
| **Main Flow**        | 1. 시스템이 “당첨 번호를 입력해주세요.”를 출력한다.<br>2. 사용자가 번호를 입력한다.<br>3. 시스템이 숫자 개수와 범위를 검증한다.                                     |
| **Alternative Flow** | - 6개가 아닌 경우, “번호는 6개여야 합니다.” 출력<br>- 중복된 번호가 있는 경우, “중복된 번호가 존재합니다.” 출력<br>- 1~45 이외의 숫자가 있을 경우, “유효하지 않은 번호입니다.” 출력 |
| **Postcondition**    | 유효한 당첨 번호 리스트가 저장된다.                                                                                                 |

### Use Case 4: 보너스 번호 입력

| 항목                   | 내용                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------ |
| **Actor (사용자)**      | 사용자는 보너스 번호 1개를 입력한다.                                                                |
| **System (시스템)**     | 시스템은 입력된 번호가 1~45 사이의 숫자인지, 당첨 번호와 중복되지 않는지 검증한다.                                    |
| **Precondition**     | 당첨 번호 입력이 완료된 상태이다.                                                                  |
| **Main Flow**        | 1. 시스템이 “보너스 번호를 입력해주세요.”를 출력한다.<br>2. 사용자가 번호를 입력한다.<br>3. 시스템이 범위와 중복 여부를 검증한다.    |
| **Alternative Flow** | - 1~45 범위를 벗어나면 “유효하지 않은 번호입니다.” 출력<br>- 당첨 번호와 중복되면 “보너스 번호는 당첨 번호와 중복될 수 없습니다.” 출력 |
| **Postcondition**    | 유효한 보너스 번호가 저장된다.                                                                    |

### Use Case 5: 당첨 내역 출력

| 항목                | 내용                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------- |
| **Actor (사용자)**   | 사용자는 구매한 로또의 당첨 결과를 확인한다.                                                                         |
| **System (시스템)**  | 시스템은 각 로또의 일치 개수를 계산하여 통계를 출력한다.                                                              |
| **Precondition**  | 당첨 번호와 보너스 번호가 모두 입력된 상태이다.                                                                       |
| **Main Flow**     | 1. 시스템이 각 로또 번호를 당첨 번호와 비교한다.<br>2. 일치 개수를 기준으로 분류한다.<br>3. “당첨 통계”와 함께 일치 개수 및 상금 정보를 출력한다. |
| **Postcondition** | 당첨 결과가 사용자에게 출력된다.                                                                            |

### Use Case 6: 수익률 계산 및 출력

| 항목                | 내용                                                                                        |
| ----------------- | ----------------------------------------------------------------------------------------- |
| **Actor (사용자)**   | 사용자는 총 수익률을 확인한다.                                                                         |
| **System (시스템)**  | 시스템은 모든 당첨 금액의 합을 계산하여 구입 금액 대비 수익률을 출력한다.                                                |
| **Precondition**  | 당첨 내역이 계산된 상태이다.                                                                          |
| **Main Flow**     | 1. 시스템이 모든 당첨 금액을 합산한다.<br>2. 수익률 = (총 당첨금 / 구입금액) × 100 계산<br>3. 소수점 둘째 자리에서 반올림하여 출력한다. |
| **Postcondition** | 총 수익률이 사용자에게 출력된다.                                                                        |

# 프로그래밍 요구 사항

- 자바스크립트 코드 컨벤션을 지키면서 프로그래밍한다.
- JavaScript Style Guide를 원칙으로 한다.
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다.
- 3항 연산자를 쓰지 않는다.
- Jest를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
- 구현한 기능에 대한 단위 테스트를 작성한다.
- 객체 이름을 축약하지 않는다.
- 스페이스와 탭을 혼용하지 않는다. => PR 이후 다시 검토해보기
- 의미 없는 주석을 달지 않는다.
- 값을 하드 코딩하지 않는다.
- 클래스는 필드, 생성자, 메서드 순으로 작성한다.
- 처음부터 큰 단위의 테스트를 만들지 않는다.
